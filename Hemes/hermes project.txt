4. Do not create a profile for yourself. You stay the main agent.

Part 03 / 03
The stay-quiet prompts (Tip 4)
Scheduled jobs (Hermes calls them cron jobs) run on their own: check my inbox every hour, scan these sites every morning, watch this server. Most runs find nothing new, but each one still sends you a message to say so. Hermes has a built-in way to skip those: when a scheduled job's reply is exactly [SILENT], Hermes does not send it at all.
